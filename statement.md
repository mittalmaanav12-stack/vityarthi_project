# PASSWORD GENERATOR

## 1. Problem Statement

Creating strong and secure passwords manually can be difficult and time-consuming. Many users use short or repeated passwords, which can make their accounts vulnerable to unauthorized access.

The purpose of this project is to develop a **Python-based Password Generator** that automatically creates random passwords according to the user's requirements. The user can specify the minimum password length and choose whether the password should contain numbers and special characters.

The program uses Python's **Random** and **String** modules to generate passwords containing letters, numbers, and special characters.

---

## 2. Scope of the Project

The scope of this project is to provide a simple and efficient tool for generating random passwords.

The project includes:

* Taking the minimum required password length from the user.
* Allowing the user to choose whether numbers should be included.
* Allowing the user to choose whether special characters should be included.
* Generating a random password based on the selected requirements.
* Ensuring that the generated password satisfies the user's selected conditions.
* Displaying the generated password to the user.

The project is designed as a **basic password-generation application** and does not include features such as password storage, account management, encryption, or online security services.

---

## 3. Target Users

The Password Generator can be used by:

* **Students** – to create strong passwords for educational accounts and applications.
* **General users** – to generate passwords for personal online accounts.
* **Beginners learning Python** – to understand functions, loops, conditional statements, user input, and Python modules.
* **Developers and programmers** – as a basic example of implementing a random password-generation system.
* **Small organizations** – for generating temporary passwords when needed.

---

## 4. High-Level Features

### 1. Custom Password Length

The user can enter the minimum length required for the password.

### 2. Letter Generation

The program can generate passwords using uppercase and lowercase English letters.

### 3. Number Option

The user can choose whether numbers should be included in the password.

### 4. Special Character Option

The user can choose whether special characters such as `@`, `#`, `$`, `%`, etc. should be included.

### 5. Random Password Generation

The program randomly selects characters using Python's `random` module to create a different password each time.

### 6. Requirement Validation

The program checks whether the generated password contains the required numbers and/or special characters based on the user's choices.

### 7. User-Friendly Input

The program interacts with the user through simple questions and generates the password according to their answers.

### 8. Immediate Output

The generated password is displayed immediately after the user provides the required information.

---

## Conclusion

The Password Generator is a simple Python project designed to automatically generate customizable random passwords. It demonstrates the practical use of **functions, loops, conditional statements, strings, user input, and Python modules** while providing a useful application for creating passwords.
